Acronyms defined with `\newacronym` (glossaries package) are
expanded: `\gls` gives the long form with the short form on first
use, and the short form after that.

```
% pandoc -f latex -t plain
\documentclass{article}
\usepackage[acronym]{glossaries}
\newacronym{html}{HTML}{HyperText Markup Language}
\begin{document}
\gls{html} and \gls{html}.
\end{document}
^D
HyperText Markup Language (HTML) and HTML.
```

```
% pandoc -f latex -t plain
\newacronym{cpu}{CPU}{Central Processing Unit}
\newacronym{gpu}{GPU}{graphics processing unit}
The \gls{cpu} socket; a \gls{cpu} socket. \glspl{gpu}, \acrlong{gpu},
\acrshort{gpu}, \acrfull{gpu}, \glspl{gpu}. \gls{undefined}.
^D
The Central Processing Unit (CPU) socket; a CPU socket. graphics
processing units (GPUs), graphics processing unit, GPU, graphics
processing unit (GPU), GPUs. undefined.
```
